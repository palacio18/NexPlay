# NexPlay

Biblioteca personal de videojuegos creada con HTML, CSS y JavaScript.

## Estructura

```text
NexPlay/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── imagenes/
│   ├── warzone.webp
│   ├── resident-evil-4.webp
│   └── god-of-war.webp
├── favicon.svg
└── README.md
```

## Funciones

- Catálogo de videojuegos con fichas completas.
- Búsqueda por nombre, género, plataforma y descripción.
- Filtros por género, estado y favoritos.
- Orden por calificación, nombre y año.
- Agregar, editar y eliminar juegos propios.
- Favoritos y juegos guardados con `localStorage`.
- Modal accesible con detalles del juego.
- Tema claro y oscuro.
- Diseño responsive.

## Ejecutar localmente

Abre `index.html` en el navegador. No necesita instalación ni dependencias.

## Publicar

Sube toda la carpeta `NexPlay/` a un servicio de hosting estático como Netlify Drop, GitHub Pages o Vercel. `index.html` debe permanecer en la raíz del proyecto.
